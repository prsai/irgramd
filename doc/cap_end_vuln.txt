IRC user registration ignoring PASS in CAP END

Description:
During IRC user registration process, if capability negotiation is in course
and ends (with CAP END command), the user is registered without taking into
account that password is not given (if required via PASS command).

Impact:
If irgramd is listening outside localhost, remote authentication without
user/password is possible, assigning nick "None". In this state not all
commands or chats will work.
